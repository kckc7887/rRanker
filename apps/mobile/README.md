# rRanker Mobile

Expo SDK 54 + Expo Router + TypeScript strict。需要 Node.js 22.13 或更高版本。

## 开发命令

```powershell
npm ci --no-audit --no-fund
npm test
npm run typecheck
npm run lint
npm run check:generated
npm start
npm run android
```

运行链路、存储与构建见 [技术架构](../../docs/technical-architecture.md)，公共入口见 [公共逻辑](../../docs/shared-logic.md)。

# 应用中二名牌四层布局坐标

## 改动原因

中二节奏成绩图片的玩家信息区域需要使用布局调试器确认后的坐标。名牌板、称号和角色必须使用完整图片，保持各自原始宽高比，不允许通过裁剪或拉伸适配旧网格。

## 具体实现

- 在 576×228 名牌坐标系中应用以下位置：名牌板 `x=-1, y=9, w=576, h=228`，称号 `x=181.78, y=39.78, w=370, h=45.03289473684211`，Rating 框 `x=187, y=81, w=276, h=89`，角色 `x=463, y=83, w=86, h=86`。
- 移除玩家信息区原有的四行 CSS Grid 与占位分隔元素，改为按名牌板源坐标等比换算后的绝对定位。
- 名牌板、称号和角色图片统一使用 `object-fit: contain` 与居中定位，称号槽和角色框不再使用裁切、额外背景、边框或阴影。
- 保留称号文字、玩家首字和缺失名牌板的素材加载失败回退逻辑。
- 更新中二成绩图片 HTML 测试，覆盖 1080px 导出宽度下的换算坐标、完整图片显示规则、直角样式和关闭称号或角色后的固定位置。

## 期望输出

- 导出图中的四项玩家信息元素与调试器给出的坐标一致。
- 名牌板、称号和角色完整显示，比例分别保持源图 576×228、608×74 和 128×128，不出现裁剪或拉伸。
- Rating 框继续使用领域颜色，并保持现有等级、玩家名、分隔线和 Rating 文本结构。

## 实际输出

- 1080px 生产 HTML 浏览器预览中，名牌板、称号、Rating 框和角色均按换算后的绝对坐标显示；三张图片自然尺寸正确，计算样式均为 `object-fit: contain`，控制台无错误。
- `lint` 通过（0 error，保留既有 26 条 warning），`typecheck` 通过，Vitest 104 个文件共 651 项测试通过，Jest 35 个测试套件共 188 项测试通过。

# ADOFAI 成绩卡与歌曲详情二次重构

## 改动原因

上一版 ADOFAI 成绩卡的信息密度和关卡详情层级仍未贴合应用内其它游戏：成绩列表右侧堆叠了难度与 Impact，详情使用 16:9 头图并将难度放在封面内，判定、玩家成绩、谱师和标签也缺少清晰的阅读顺序。本次按用户给出的判定表格样式和应用现有方形歌曲详情结构重新整理。

## 具体实现

- 最佳与成绩卡继续复用 `GameScoreCard`，左侧改为标题、Score、纯百分比 XACC、纯倍速和底部紧凑难度徽章；右侧只保留垂直居中的 Impact，列表不再渲染 WF、PP 或判定明细。
- `TufDifficultyBadge` 读取 TUF `difficulty.color` 并自动选择深浅文字，完整识别 P1–P20、G1–G20、U1–U20；特殊难度保持原中性/特殊样式。
- 详情头图改为全宽正方形，保留 TUF 代理图、原图、难度图标和本地图标回退；封面只显示 `#ID`，歌名与艺术家均复用 `AutoScrollText` 单行滚动。
- 新增 `/v2/database/passes/level/{id}` 只读查询及无嵌套关卡的成绩 Schema，按当前绑定 PID 选择 Score V2、XACC、Impact、成绩 ID 依次最优的记录，不写入 SQLite。
- 单难度卡复用 `GameChartResultCard`，展示 PGU 字母、难度数字、Base Score、Score、WF/PP、XACC、倍速、谱师、上游标签和 3+4 七项判定矩阵；总物量按关卡物量、自动物量、完整判定求和依次回退。
- TUF 标签图标固定到 TUFHelper 提交 `7a5b84eeea6fc0ce86d25da07d19595481a31d7e` 的 GitHub Raw 资源，使用已核对的名称映射；未映射或加载失败时保留文字标签。
- 歌曲信息区仅保留策展、社区统计和 TUF 关卡页入口；收藏与个人标签继续使用原公共曲库路径。

## 期望输出

- 成绩卡可以快速扫读 Score、XACC、倍速、难度和 Impact，难度不再占据整行或右侧空间。
- 详情页与其它游戏保持相同的方形封面和单难度卡层级，同时以 ADOFAI 判定矩阵作为主要视觉识别点。
- 当前玩家未绑定、未游玩、成绩接口失败、标签图标失败或媒体图片失败时，页面结构仍然完整且可继续使用。

# 舞萌 U·TA·GE 原曲信息与展示

## 改动原因

U·TA·GE 曲目在上游拥有独立歌曲 ID 和带属性前缀的标题，但封面、别名及大部分歌曲资料应沿用原曲。原有通用难度卡片也会显示不适用于 U·TA·GE 的 Rating、定数和谱师信息，需要按其专用展示规则调整。

## 具体实现

- 以 U·TA·GE 歌曲 ID 减 100000 获取原曲 ID，并用原曲 ID 加载封面。
- 移除 U·TA·GE 歌曲标题开头的半角、全角或书名号式方括号属性。
- 从原曲继承曲师、BPM、分类、地区、版权、版本与别名，同时保留 U·TA·GE 自身歌曲 ID，确保收藏和个人曲库状态不变。
- 曲库卡片使用 U·TA·GE 四色渐变显示属性汉字；详情难度卡片右上角显示属性汉字及原始等级文本。
- U·TA·GE 成绩和详情不再显示 Rating，详情不再显示谱师；达成率、DX 分数、评级、FC/FS、说明与双人物量保持可用。
- 补充领域工具、LXNS 曲库映射、曲库界面、详情界面及成绩卡片的自动化测试。

## 期望输出

- U·TA·GE 曲目使用原曲封面与歌曲资料，标题不含固定属性前缀。
- 曲库和详情能准确呈现属性汉字与等级，且不会出现 Rating 或谱师字段。
- 收藏仍绑定 U·TA·GE 自身歌曲，不受原曲资料复用影响。

# 桌面端舞萌示例账号首版

## 改动原因

rRanker 需要在保留 Expo 移动端行为的前提下启动轻量跨平台桌面端开发，并先用无凭据的舞萌示例账号打通总览、最佳成绩和成绩列表闭环。桌面端还需要验证系统 WebView、SQLite 缓存、安全权限边界和 Windows 安装交付是否能够真实工作。

## 具体实现

- 将仓库整理为 npm workspaces，统一管理 `apps/mobile`、`apps/desktop` 与 `packages/core`，并迁移为根级依赖锁文件。
- 在 `packages/core` 提取舞萌领域模型、Rating/B50、曲库映射、Provider 错误、仓储契约、`ScoreService`、`FetchLike`、`LxnsCatalogProvider` 与全满示例成绩 Provider；移动端原路径保留兼容重导出，并继续注入 `expo/fetch`。
- 新增 Tauri 2 + Vite + React 19 + TypeScript 桌面应用，Rust 侧仅注册 HTTP、SQL 插件与 SQLite 迁移；桌面标识为 `com.rranker.desktop`，现有产品版本字段保持不变。
- SQLite 增加初始化标记、账号、曲库快照和账号成绩快照。首次运行事务性创建 `maimai:test`，删除后不自动复活，并支持手动重新添加。
- HTTP capability 仅开放 LXNS 舞萌公共接口，SQL capability 仅补充读写所需命令；CSP 只放行 LXNS 舞萌封面资源。
- 实现缓存优先启动、后台单次刷新、12 秒超时、无自动重试、限流/离线缓存回退和手动刷新防重入。
- 实现桌面工作台侧栏、账号与数据状态顶栏、总览页、B35/B15 最佳卡片页和可排序筛选的虚拟化成绩表格，并跟随系统深浅色主题。
- 补充共享核心、桌面账号生命周期、页面导航、B35/B15、排序筛选及缓存行为测试，同时保持移动端兼容回归。

## 期望输出

- Windows、macOS、Linux 共用同一桌面代码库，首批 Windows 11 能构建并安装 NSIS `setup.exe`。
- 首次联网启动自动创建示例账号并生成完整曲库与成绩快照；后续可先显示缓存，刷新失败时不清除最近有效数据。
- 示例成绩覆盖所有有效非宴会场谱面，统一生成 `101% / AP+ / FDX+ / 满 DXScore`，并复用共享 B50 逻辑计算 Rating。
- 删除示例账号后重启不自动恢复，用户可从空态重新添加。
- 移动端原有页面、依赖版本和运行行为保持兼容。

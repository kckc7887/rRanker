# 舞萌落雪同步引导双页

## 改动原因

舞萌上传原先只有 Score Hub 好友码流程。舞萌落雪账号也需要复用中二节奏已有的 HTTP 代理与微信离线同步引导，但不能改变本地、水鱼账号和落雪账号正常打开时直接进入好友码界面的既有路径。

## 具体实现

- 将落雪代理地址、复制交互、微信离线同步步骤和完成后刷新逻辑抽成舞萌、中二共用内容。
- 舞萌落雪 OAuth 账号的上传弹层顶部增加“好友码 / 同步引导”选择栏；每次打开默认选中好友码页。
- 本地、水鱼等非落雪舞萌账号继续直接显示原好友码页，不显示选择栏。
- 同步引导使用官方固定舞萌微信链接 `https://maimai.lxns.net/api/v0/maimai/wechat/auth`，并说明离线同步只更新已经绑定到落雪账号的玩家数据。
- 好友码上传或落雪数据刷新进行中锁定页面切换；落雪刷新回退到缓存时保留引导并提示重试。
- 补充落雪离线同步协议记录，以及顶部选择栏、同步引导、总览入口和原好友码页的自动化测试。

## 期望输出

- 普通舞萌账号点击上传后仍直接进入好友码界面。
- 舞萌落雪账号点击上传后也默认进入好友码界面，但顶部可以切换到独立同步引导页。
- 同步引导可复制代理服务器、端口、完整地址和舞萌微信离线同步链接，完成后可刷新当前落雪账号。
- 中二节奏原同步引导行为保持不变。

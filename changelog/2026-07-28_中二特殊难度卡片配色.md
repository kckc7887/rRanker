# 中二特殊难度卡片配色

## 改动原因

- 中二节奏歌曲详情页的 ULTIMA 难度卡片仍为浅灰底，未完整体现黑红主题。
- WORLD'S END 难度卡片仍使用普通淡紫底，与其专属霓虹渐变标签不一致。

## 具体实现

- ULTIMA 难度卡片改为 `#17171A` 黑底与 `#E83A58` 红色描边、按钮，浅色和深色主题均保持黑红配色。
- WORLD'S END 难度卡片直接复用难度标签的青、紫、粉、橙四色横向渐变，并使用相同的半透明深色遮罩。
- 两种特殊卡片统一使用高对比度浅色文字、分隔线和物量数据；标签编辑区增加浅色承载面，保证黑色与渐变背景下的可读性。
- 补充 ULTIMA 背景与描边断言，以及 WORLD'S END 卡片和标签渐变一致性断言。

## 期望输出

- ULTIMA 难度卡片呈现明确的黑底红边配色。
- WORLD'S END 难度卡片与其标签使用完全一致的四色渐变。
- 特殊卡片内的等级、成绩、谱师、物量、按钮和标签编辑控件保持清晰可读。

## 实际输出

- ULTIMA 卡片已固定为黑底红边，WORLD'S END 卡片已复用标签渐变与遮罩。

- `npm run typecheck`：通过。
- `npx eslint src/components/chunithm/ChunithmSongDetail.tsx tests/chunithm-song-detail.test.tsx`：通过。

# 修复舞萌谱面标签删除线

## 改动原因

DXRating 的部分标签说明使用 `~~内容~~` 表示删除线。原 Provider 为了输出纯文本直接移除了 `~~` 标记，导致单标签说明通知和全部标签弹层都无法还原源网站的删除线效果。

## 具体实现

- 将 DXRating 说明解析为保留顺序的普通片段和删除线片段，同时继续提供不含 Markdown 标记的纯文本说明用于无障碍与兼容展示。
- Markdown 链接仍降级为可读的链接文字，不把 URL 或 Markdown 语法直接展示给用户。
- 将 DXRating 快照 Schema 版本从 2 提升到 3，使缺少富文本片段的旧缓存失效并重新获取。
- 扩展顶部通知消息契约，允许在不影响现有纯文本调用方的情况下渲染带删除线的文本片段。
- 单标签说明通知和“谱面标签”页式弹层均对删除线片段应用 `textDecorationLine: line-through`。
- 更新 API 协议文档，并补充 Provider 解析、通知样式和弹层样式测试。

## 期望输出

- DXRating 源数据中由 `~~` 包裹的说明片段在应用内显示删除线，其余文字保持正常样式。
- 单标签说明通知和全部标签弹层的效果一致。
- 普通说明、无说明回退、无障碍文本及现有通知不受影响。

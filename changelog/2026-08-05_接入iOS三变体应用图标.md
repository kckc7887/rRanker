# 接入 iOS 三变体应用图标

## 改动原因

准备 EAS 构建 IPA 前，需要把新的应用图标（三个配色：彩色、深色、着色）接入 iOS 构建。iOS 图标要求 1024×1024 无透明通道的 PNG，而设计稿为 SVG；Expo SDK 54 的 `ios.icon` 支持 light/dark/tinted 三变体，由系统按外观自动切换（tinted 用于 iOS 26 Liquid Glass）。

## 具体实现

1. 将三张 SVG 设计稿转换为 1024×1024 PNG，并展平为无 alpha 通道的 24bpp（原转换结果含 alpha 通道，背景渐变区 alpha=254，不符合 App Store 无透明要求）：
   - `rRanker icon.svg` → `icon-light.png`
   - `rRanker icon Drak.svg` → `icon-dark.png`
   - `rRanker icon Tinted.svg` → `icon-tinted.png`
   - 输出到 `apps/mobile/assets/images/`
2. `apps/mobile/app.json` 的 `ios` 下新增：
   ```json
   "icon": {
     "light": "./assets/images/icon-light.png",
     "dark": "./assets/images/icon-dark.png",
     "tinted": "./assets/images/icon-tinted.png"
   }
   ```
3. 验证：
   - `expo config --type public` 确认配置生效
   - 检查 `@expo/prebuild-config` 的 `withIosIcons.js`：三变体对象会生成 `AppIcon-*-dark/tinted` 图片，并在 Contents.json 写入 `appearances: [{ appearance: "luminosity", value: "dark"/"tinted" }]`
   - Windows 无法本地生成 iOS 工程，EAS 云端（macOS）prebuild 时自动生成
4. 补充提交图标源文件：`assets/images/` 下的 `rRanker icon.svg`、`rRanker icon Drak.svg/png`、`rRanker icon Tinted.svg/png`、`rRanker icon.png`（设计稿与转换原图归档入库）

## 期望输出

- 三个 1024×1024、无 alpha 的 PNG 存在于 `apps/mobile/assets/images/`
- app.json 配置合法，prebuild 时 iOS 工程生成含 light/dark/tinted 三种外观的 AppIcon.appiconset
- 现有功能无回归

## 实际输出

- 三个 PNG 已生成并验证：1024×1024、Format24bppRgb（无 alpha）
- app.json 配置通过 `expo config` 校验，源码确认三变体生成逻辑
- lint 0 errors、typecheck 通过、Vitest 109 文件 696 用例通过、Jest 36 套件 193 用例通过
- 后续待用户购买 Apple Developer 账号后执行 `eas build -p ios --profile production`

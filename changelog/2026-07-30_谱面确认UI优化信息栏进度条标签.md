# 谱面确认 UI 优化：信息栏、进度条、标签

## 改动原因
1. Canvas 上叠加的 BPM、节拍、FPS、连击、BREAK 信息遮挡谱面，改为独立信息栏。
2. 进度条使用浏览器默认样式不够美观。
3. 音量标签"乐音"/"打击"含义不够直观。

## 具体实现
1. **信息栏**：在标题与 Canvas 之间新增 `#info-bar`，水平排列显示 BPM、节拍位置、连击(已完成/总数)、BREAK(含/无保护)、FPS。Canvas 上原有的 HUD 叠加通过 `renderer.setShowBpm(false)` 等关闭。
2. **MainRenderer 扩展**：新增 `FrameOverlayInfo` 接口与 `frameOverlay` 公开属性，在每帧 `renderNotes` 时填充；新增 `setShowBpm`、`setShowNoteTotal`、`setShowBreakCount` 公开方法。
3. **进度条**：自定义 `#seek` 样式，4px 圆角轨道 + 14px 圆形滑块（白边 accent 填充）。
4. **标签文字**：音量标签从"乐音"/"打击"改为"音乐"/"打击音"。

## 期望输出
- 信息栏位于标题下方，Canvas 画面纯净无 HUD
- 进度条为自定义圆角样式
- 标签文字更新

## 实际输出
与期望一致。

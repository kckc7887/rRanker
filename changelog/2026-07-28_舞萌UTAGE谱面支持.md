# 舞萌 U·TA·GE 谱面支持

## 改动原因

舞萌曲库此前没有完整解析和展示 LXNS 的 `difficulties.utage`，个人成绩读取也会跳过对应记录。固定的 `level_index=0` 还存在被普通难度映射为 BASIC 的风险；`協`属性谱面的左右物量、U·TA·GE 不参与 Rating 的规则以及个人曲库持久化边界也未被表达。

## 具体实现

- 扩展舞萌领域模型，增加 `UTAGE` 谱面类型、`utage` 难度、属性/说明/BUDDY 元数据和左右物量结构。
- LXNS 曲库单独解析 `difficulties.utage`，固定领域键为 `UTAGE:0`；恢复 LXNS 与 Score Hub 的合法 U·TA·GE 成绩。
- 曲库、成绩和详情统一显示 `U·TA·GE`，复用中二 WORLD'S END 的同一四色渐变；成绩与详情保留 DX 分数、评级和 FC/FS；难度筛选增加 U·TA·GE，SD、DX 和定数范围保持与其互斥。
- 详情显示属性与说明；`is_buddy=true` 时纵向显示 1P、2P 两张物量表，并分别向容错计算器传入各自物量。
- U·TA·GE 的 Rating 显示 `—`，不提供计算器入口，并从 B35/B15、总 Rating、未匹配数量、普通/自定义最佳图片和随机谱面中排除。
- 个人曲库支持 U·TA·GE 收藏、练习清单和谱面标签；通过幂等 SQLite 表迁移扩展约束并保留原条目和标签，备份协议版本保持不变。
- 新增 provider、成绩映射、筛选、详情、Rating 隔离、最佳图片、随机谱面、备份和 SQLite 迁移测试；同步 API 协议与移动端测试说明。

## 期望输出

- 默认曲库和 U·TA·GE 难度筛选能找到目标谱面，所有标签严格显示 `U·TA·GE`。
- U·TA·GE 成绩正常显示达成率、DX 分数、评级与 FC/FS，但不影响任何 Rating 结果。
- `協`谱面分别显示和使用 1P、2P 物量，空物量安全降级。
- 已有个人曲库数据在约束迁移、备份与恢复过程中保持完整。
- 不修改任何版本号，不将 U·TA·GE 加入随机谱面工具。

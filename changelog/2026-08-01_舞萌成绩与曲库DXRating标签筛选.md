# 舞萌成绩与曲库 DXRating 标签筛选

## 改动原因

舞萌歌曲详情已经能够展示 DXRating 谱面标签，但成绩页和曲库页仍无法使用这些标签定位谱面。个人曲库中的本地标签还可能与 DXRating 标签同名，因此筛选必须严格使用 DXRating 标签 ID 与远端谱面关系，避免本地数据误命中。

## 具体实现

- 为舞萌成绩和曲库筛选状态增加 DXRating 数字标签 ID 多选，重置筛选时同步清空，不写入 SQLite、个人曲库或备份。
- 在共用舞萌筛选栏增加始终可见的“标签”入口；实时数据可用时打开单一页式弹层，按配置、难度、评价分组及上游顺序显示彩色复选标签，并提供清空、完成和完整无障碍状态。
- 新增谱面标签索引，将 DXRating 关系一次性映射到规范化歌曲 ID、谱面类型和难度序号；多标签使用全部满足语义，沿用 SD/DX 精确匹配及 U·TA·GE/Buddy 唯一回退规则。
- 通用歌曲搜索增加可选谱面谓词，使曲库的类型、难度、定数、谱面版本与全部标签在同一张谱面上共同求交；成绩按成绩对应的精确谱面判断。
- 标签快照变化时自动剔除失效选择；加载期间保留选择且不阻塞列表，无缓存失败时清空选择。成绩与曲库来源状态均展示 DXRating 的实时、缓存或不可用状态。
- 更新 DXRating API 协议说明，并补充索引、歌曲 ID 规范化、AND 语义、同谱面求交、分组弹层、来源状态及本地同名标签隔离测试。

## 期望输出

- 舞萌成绩和曲库可以按一个或多个 DXRating 标签筛选，多个标签必须由同一张谱面全部满足。
- 本地标签、全局标签预设和个人曲库标签不会影响筛选结果。
- 标签加载或不可用时不阻塞原列表和其他筛选条件，缓存与失效选择能够安全处理。

## 实际输出

- 标签入口、多选弹层、折叠摘要、清空与完成交互均已接入成绩和曲库；标签颜色、分组顺序和选中无障碍状态通过页面级测试。
- 曲库与成绩均通过精确谱面索引完成 AND 过滤，同名本地标签不会产生远端标签命中，SD/DX 与 U·TA·GE/Buddy 边界均有测试覆盖。

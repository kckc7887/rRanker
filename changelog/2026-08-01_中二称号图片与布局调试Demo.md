# 中二称号图片与布局调试 Demo

## 改动原因

中二节奏成绩图片的玩家信息区仍需继续校准，同时称号槽应显示 `/trophy/{trophy_id}.png` 对应的称号图片，而不是默认显示称号文字。为减少反复修改 CSS 后才能确认位置的问题，需要提供可实时调整称号、Rating 框和角色位置与尺寸的调试 Demo。

## 具体实现

- 在成绩图片 HTML 输入中增加称号图片远程地址，并在预处理后的 Data URI 不可用时直接使用 `https://assets2.lxns.net/chunithm/trophy/{trophy_id}.png`。
- 称号图片仍保留加载失败回退：只有图片加载失败时才显示称号文字，避免导出区域空白。
- 中二成绩图片页面统一生成并传递当前 `trophy_id` 对应的图片地址，不修改称号选择、隐藏规则或数据模型。
- 补充单元测试，验证指定 `trophy_id` 会生成并写入正确的称号图片路径。
- 提供独立布局调试 Demo，可选择、拖动称号图片、Rating 框和角色，并通过滑块实时调整各元素的 `x`、`y`、宽、高；可将当前参数直接回传给 Codex。

## 期望输出

- 选中称号时，导出的玩家信息区优先显示 `/trophy/{trophy_id}.png` 图片。
- 图片预处理失败不会立即退回文字，WebView 会继续尝试加载远程称号图片；仅远程图片也失败时显示称号文字。
- 用户可在 Demo 中实时观察并调整三个元素的位置和尺寸，再将确定的参数用于生产布局。

## 实际输出

- 称号图片地址已接入导出 HTML，Data URI 与远程地址均可作为图片来源，文字仅作为加载失败回退。
- 浏览器实测 Demo 的元素选择、拖动、坐标滑块和尺寸滑块均会实时更新，参数回传按钮可用，控制台无错误。

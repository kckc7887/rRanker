# 中二成绩图样式自定义

## 改动原因

中二节奏 Best50 成绩图 HTML 已改为使用角色/名牌板/称号素材，需要在屏幕层接入与 Phigros/舞萌一致的样式选择与预览流程，并更新偏好解析测试。

## 具体实现

- `ChunithmBestImageScreen` 使用 `DEFAULT_CHUNITHM_BEST_IMAGE_STYLES`（version 2），移除 `map_icon` / `iconDataUri`。
- 挂载时加载 `loadChunithmBestImageCollections`，在 Selection 行下方增加角色/名牌板/称号三行样式 UI 与 `ChunithmBestImageStylePicker`。
- 通过 `resolveChunithmBestImageStyleId` 解析 ID，加载 character/plate/trophy data URI，并将 `hide*`、`trophyName` 传入 `buildChunithmBestImageHtml`。
- 随机模式在集合加载后若无有效 ID 则一次性抽取并写入偏好（与舞萌/Phigros 一致）。
- 补充 `parseChunithmBestImageStylePreferences` version 2 与 v1 迁移测试。

## 期望输出

- 屏幕可选择/预览/关闭角色、名牌板、称号，预览与导出 HTML 使用对应素材。
- `tests/chunithm-best-image.test.ts` 全部通过，`tsc --noEmit` 无错误。

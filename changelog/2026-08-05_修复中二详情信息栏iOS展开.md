# 修复中二详情页信息栏 iOS 无法点击展开

## 改动原因

用户反馈：中二节奏歌曲详情页封面下信息栏（分类/BPM/版本/地图）文字过长被截断为两行省略号后，点击整个格子没有展开反应（iOS）。调查发现信息栏并非独立实现，而是复用共享组件 `SongMetadataTable`，展开/收起逻辑本身存在；问题是该组件在 iOS 上默认使用 React Native 原生 `Pressable`，在页面外层 ScrollView 内点击会被手势系统取消，`onPress` 无法触发。舞萌详情页早已通过传入 `interaction="platform-detail"`（iOS 改用 `GesturePressable` + 局部手势根容器）规避此问题（见 2026-07-15 滚动区按钮点击修复），而中二详情页未传该参数，导致同一问题在中二板块复发。

## 具体实现

- `apps/mobile/src/components/chunithm/ChunithmSongDetail.tsx`
  - `SongMetadataTable` 增加 `interaction="platform-detail"`，iOS 上信息栏格子改用 `GesturePressable` 并由组件自动包裹 `GestureHandlerRootView`，点击不再被外层 ScrollView 手势取消。
  - 增加 `cellRootStyle={styles.metadataCellRoot}` 以让组件为每个格子提供手势根容器（无 `cellRootStyle` 时不会包根容器）。
  - 新增样式 `metadataCellRoot: { minWidth: 0 }`，与舞萌一致；`flex: 1` 由组件从 cell 自动移到 root，各格子宽度分配不变，视觉无变化。
  - Android 不受影响：`platform-detail` 在 Android 仍走原生 `Pressable` 与普通 `View`，符合既有的 Android 原生触控修复。

## 期望输出

- iOS 上中二详情页信息栏文字超过两行时点击格子可展开/收起全文，与舞萌行为一致。
- 信息栏布局、字体、间距、截断行为与展开视觉均不改变；Android 行为不改变。

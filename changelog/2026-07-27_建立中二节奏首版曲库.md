# 建立中二节奏首版曲库

## 改动原因

为中二节奏建立可进入的首版游戏模块，在正式账号、成绩同步和成绩展示尚未接入前，先用可持久化的无成绩临时账号承载全量曲库浏览能力。中二节奏与舞萌虽然共用 LXNS 服务根地址，但接口响应、难度结构和曲绘规则不同，因此需要独立建模和缓存。

## 具体实现

- 注册“中二节奏”游戏、`chunithm-temp` 临时账号来源和完整游戏能力映射，并在游戏选择器、账号分组及账号头像中使用 `chunithm.png`。
- 新增固定账号 `chunithm:temp` 的持久化开关，支持一键添加后自动进入、重启恢复、删除和重新添加，不生成成绩快照或凭据。
- 新增独立的中二领域类型和 LXNS 曲库 Provider，校验 `songs`、`genres`、`versions` 及平铺难度，保留 ULTIMA、WORLD'S END、`origin_id`、`kanji`、`star` 等中二专属数据。
- 新增独立 `chunithm-catalog` 资源缓存和存储管理映射；网络失败时回退最近一次有效缓存，清理中二存储时同步删除。
- 曲库页增加中二专属列表，保持接口顺序，展示曲绘、曲名、艺术家、版本与各难度定数，并支持曲名、ID、艺术家和谱师关键词搜索。
- 中二总览显示临时账号、RATING `—` 和“当前仅开放曲库”，隐藏同步、上传、收藏和工具入口；成绩与 Best 页面沿用未接入空态。
- 补充中二公共 API 协议说明、Provider/缓存/曲库界面/账号会话/存储回归测试，并修正完整校验中暴露的接口可见性和既有测试桩兼容问题。

## 期望输出

- 用户可从游戏管理一键添加中二节奏临时账号，自动切换到中二总览，并在重启后保留账号和选中状态。
- 曲库从 `GET /api/v0/chunithm/song/list` 获取，无需鉴权，可浏览全量歌曲并进行本地关键词搜索。
- 首版不显示筛选器、收藏按钮、歌曲详情跳转、成绩同步或上传操作。
- 网络请求失败时优先展示已有缓存；曲绘加载失败时显示占位内容。
- 不影响现有舞萌、Phigros 与测试游戏功能，不修改应用版本号。

## 实际输出

- 已完成中二节奏入口、临时账号持久化、独立曲库 Provider、磁盘缓存、曲库列表与本地搜索，并接入用户提供的透明 PNG 图标。
- 已覆盖 BASIC、ADVANCED、EXPERT、MASTER、ULTIMA 与 WORLD'S END；WORLD'S END 曲绘可按 `origin_id` 回退到原曲。
- `npm run typecheck` 通过。
- `npm run lint` 通过，0 个错误；保留仓库现有 20 条警告。
- `npm test` 通过：Vitest 85 个文件、458 项测试，Jest 22 个套件、114 项测试全部通过。

# WORLD'S END 难度卡片深色模式

## 改动原因

WORLD'S END 难度卡片柔化渐变后固定使用白色遮罩和深色文字，在应用深色模式下仍呈现浅色卡片，卡内标签编辑区域也未跟随主题。

## 具体实现

- 浅色模式继续使用 52% 白色遮罩、深紫黑文字和浅色标签编辑区域。
- 深色模式改用 62% 深紫遮罩、白色文字、浅色分隔线与深色标签编辑区域。
- WORLD'S END 操作按钮在深色模式下恢复适合深色背景的交互配色。
- 新增深色主题测试状态，验证遮罩、等级文字和标签编辑区域的实际颜色。

## 期望输出

- WORLD'S END 卡片在浅色模式下保持柔和的浅色渐变。
- 切换深色模式后，卡片变为压暗的霓虹渐变，文字和输入区域清晰可读，不再出现浅色卡片突兀或内容对比不足。

## 实际输出

- WORLD'S END 卡片已按主题切换遮罩与内容颜色，深色模式使用 `rgba(20,14,38,0.62)` 遮罩。
- `npm run test:ui -- --runTestsByPath tests/chunithm-song-detail.test.tsx tests/chunithm-catalog-screen.test.tsx tests/chunithm-score-pages.test.tsx`：3 个测试套件、12 个测试全部通过。
- `npm run typecheck`：通过。
- `npx eslint src/components/chunithm/ChunithmSongDetail.tsx tests/chunithm-song-detail.test.tsx`：通过。

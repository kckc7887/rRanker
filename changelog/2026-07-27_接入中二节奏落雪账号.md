# 接入中二节奏落雪账号

## 改动原因

中二节奏首版曲库此前依赖无成绩临时账号进入，无法使用落雪账号读取玩家资料与成绩，也无法复用已经绑定在舞萌 DX 上的同一份落雪授权。需要补齐正式账号绑定、跨游戏凭据复用与个人数据缓存基础，为后续同步引导和成绩展示提供稳定入口。

## 具体实现

- 将远程会话存储升级为 v3，分离游戏账号与远程凭据；同一份 LXNS OAuth 凭据可以同时关联舞萌 DX 和中二节奏，刷新令牌后会同步更新全部关联账号。
- 增加 v2 到 v3 的安全迁移、按账号兼容读取、单边解绑保留凭据及最后解绑清理凭据的逻辑。
- 在舞萌 DX 与中二节奏的落雪登录弹层中加入双向“使用已有落雪账号”入口，并排除已经关联目标游戏的凭据；多账号场景由用户明确选择。
- 新增中二玩家与成绩独立模型、个人 API Provider 及账号快照服务，读取 `/user/chunithm/player` 与 `/user/chunithm/player/scores`，支持 token 刷新、超时与异常处理、缓存回退，并在映射阶段排除 WORLD'S END。
- 中二正式账号支持玩家名、两位小数 RATING、好友码优先账号 ID、待同步稳定账号 ID 和地图头像；正式绑定后移除旧临时账号入口与标记。
- 中二总览展示实时、缓存或待同步状态及成绩数量；账号列表、头像恢复、存储统计和账号数据清理同步支持中二个人快照。
- 更新 API 协议说明，并补充凭据迁移、共享刷新、双向复用、个人接口、缓存回退和登录界面的自动化测试。

## 期望输出

- 用户可以通过落雪 OAuth 正式绑定中二节奏账号并进入游戏页面。
- 已绑定其中一款游戏的落雪账号可以直接复用到另一款游戏，无需再次授权。
- 尚未在落雪同步中二数据的账号可以以“待同步”状态完成绑定，RATING 显示为 `—`。
- 中二个人数据读取失败时可回退最近有效缓存，WORLD'S END 不进入查分成绩。
- 解绑一个游戏账号不会影响仍在使用同一凭据的另一款游戏账号。

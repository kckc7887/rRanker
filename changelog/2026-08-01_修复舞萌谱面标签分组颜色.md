# 修复舞萌谱面标签分组颜色

## 改动原因

歌曲详情最初只保留了 DXRating 的“配置 / Patterns”分组，导致界面只能看到蓝色标签，“难度 / Difficulty”和“评价 / Evaluation”两组标签及其紫色、粉色样式被提前过滤。卡片内额外显示的区域标题也不符合直接展示标签的界面要求。

## 具体实现

- 重新核对实时 `/api/v1/tags` 响应，确认当前包含 3 个分组、21 个标签、6756 条谱面关系，单谱面最多可关联 21 个标签。
- Provider 改为保留所有拥有有效分组的标签，并为每个标签记录所属分组、中文分组名和分组颜色；重复标签 ID 仍按上游首次出现顺序去重。
- 将 DXRating 快照 Schema 版本从 1 提升到 2，使只包含蓝色配置标签的旧快照失效并重新获取完整数据。
- 卡片继续最多内联展示前 4 个标签，但移除“配置”或“谱面标签”区域标题，直接排列蓝、紫、粉等彩色标签及“+N”。
- 弹层、来源状态和无障碍文案统一使用“谱面标签”，弹层内不增加分组标题，保持标签原始顺序。
- 更新 API 协议文档中的分组范围、实时统计、颜色来源和无标题折叠规则。
- 测试新增三种分组颜色、全分组映射、无标题卡片布局及更新后的界面文案断言。

## 期望输出

- 同一谱面能够同时展示配置、难度和评价标签，并分别使用 DXRating 返回的蓝色、紫色和粉色分组色。
- 难度卡片中不出现额外标签区域标题，标签直接接在谱师或宴谱说明之后。
- 旧的单分组缓存不会继续遮蔽其他颜色标签，超过 4 个时仍保持“+N”折叠。

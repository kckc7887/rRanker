# 中二详情练习与搜索按钮修复

## 改动原因

难度卡在 `GestureScrollView` 内仍使用 RN `Pressable`，iOS 上点击“搜索谱面确认”等按钮常无响应；按钮样式也未对齐舞萌（描边填充、字重与间距）。

## 具体实现

- 参照舞萌增加 `DetailPressable`：Android 用 RN `Pressable`，iOS 用 `GesturePressable`，练习清单与搜索谱面确认均改用它。
- 按钮样式对齐舞萌 `action` / `chartSearchAction` / `actionText`，浅色未加入仅描边难度色，已加入与深色填充难度色。
- 同步更新 `chunithm-song-detail` 测试：补 gesture-handler mock，并适配已去掉「定数」前缀与 SourceStatus 的详情页。

## 期望输出

难度卡上两个按钮视觉与舞萌一致；点击“搜索谱面确认”可唤起哔哩哔哩深链（失败则网页回退）；练习清单可切换。

## 实际输出

相关交互与样式已按上项落地；单测 `tests/chunithm-song-detail.test.tsx` 通过。

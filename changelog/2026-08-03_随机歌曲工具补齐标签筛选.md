# 随机歌曲工具补齐 DXRating 标签筛选

## 改动原因

舞萌DX 随机歌曲工具的筛选器此前比成绩页缺少「标签」（DXRating 谱面标签）筛选，无法按标签从曲库随机选歌。本次将标签筛选补齐，使随机工具的筛选能力与成绩页完全一致，同时保留工具自身的独立持久化筛选状态。

## 具体实现

1. `src/domain/random-charts.ts`
   - `MaimaiRandomChartFilters` 新增 `selectedDxRatingTagIds: number[]`。
   - `filterMaimaiRandomCharts` 新增可选第 4 参数 `tags?: DxRatingChartTagsSnapshot`：当标签数据存在且选中标签非空时，函数内先 `buildDxRatingChartTagIndex` 建索引，再按 `dxRatingChartHasAllTags` 逐谱面过滤；标签数据不可用时跳过标签过滤（与成绩页行为一致，不清空候选池）。

2. `src/features/toolbox/random-charts-preferences.ts`
   - 持久化 schemaVersion 2 → 3；`defaultRandomChartsPreferences()` 新增 `selectedDxRatingTagIds: []`。
   - 解析逻辑接受 v2/v3 数据（v2 自动迁移，标签默认为空）；`parseTagIds` 只保留非负有限整数、先截断再去重；`toStored` 写入 schemaVersion 3，存储 key 不变。

3. `src/state/random-charts-filter.ts`
   - 状态新增 `selectedDxRatingTagIds` 与 `setSelectedDxRatingTagIds`；`preferencesFromState` 与 `clearFilters`（重置时清空标签）同步扩展，改动继续经原有保存队列持久化。

4. `src/screens/MaimaiRandomChartsScreen.tsx`
   - 引入 `useDxRatingChartTags`；新增标签有效性裁剪 effect（数据到达后剔除无效标签 ID，数据源出错时清空），与成绩页一致。
   - `filters` memo 加入标签字段；`filterMaimaiRandomCharts` 调用传入标签快照。
   - `MaimaiFilterBar` 补传 `dxRatingTags` / `selectedDxRatingTagIds` / `dxRatingTagState` / `onDxRatingTagIdsChange`，与成绩页传参一致。

## 期望输出

- 随机歌曲工具筛选器出现「标签」行，支持打开 DXRating 标签多选面板，与成绩页完全一致。
- 选中标签后候选池仅含同时满足全部选中标签的谱面；标签数据不可用时按成绩页语义跳过标签过滤。
- 标签选择随工具筛选状态持久化；v2 旧数据加载不报错并迁移为新格式。

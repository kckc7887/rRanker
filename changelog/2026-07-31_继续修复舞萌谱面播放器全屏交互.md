# 继续修复舞萌谱面播放器全屏交互

## 改动原因

舞萌谱面确认播放器进入全屏时在 iOS 上发生两次旋转，并因缺少 `UIViewControllerBasedStatusBarAppearance` 配置触发 React Native Screens 状态栏异常。退出全屏后画布仍按横屏宽度生成正方形，尺寸远超屏幕高度；全屏锁定按钮还存在椭圆变形、与控制器显隐不同步、点击画布即可意外解锁的问题，同时全屏控制器缺少播放/暂停按钮。

## 具体实现

- 将播放器全屏方向固定为单一横屏方向，避免允许两个横屏方向时再次翻转。
- 在 iOS Info.plist 配置中启用基于 ViewController 的状态栏外观，满足 React Native Screens 的系统栏控制要求。
- 新增独立画布尺寸计算，将全屏及退出旋转期间的画布边长限制为容器宽度与视口高度的较小值，并监听 `visualViewport` 尺寸变化。
- 全屏锁定按钮重置全局按钮继承的最小宽度与内边距，保持 36×36 正圆；按钮只在控制器可见时显示。
- 将锁定语义改为固定控制器显示：锁定状态不再自动隐藏，也不会因点击画布解除，只能再次点击锁按钮解锁。
- 在全屏传输控制器中央加入播放/暂停按钮，并与普通模式按钮和播放结束状态同步。
- 重新构建播放器 HTML、JavaScript 和 bundle，并补充横屏/退出过程画布短边限幅测试。

## 期望输出

- 点击全屏按钮只旋转一次，iOS 不再出现状态栏配置异常。
- 横屏全屏和退出旋转期间画布均不超过可用屏幕短边。
- 锁按钮保持正圆，并与播放控制器同步出现和消失。
- 锁定后点击画布不会解锁或隐藏控制器，只有再次点击锁按钮才会解锁。
- 全屏控制器具有可正常切换且状态同步的播放/暂停按钮。

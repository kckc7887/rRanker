# 机厅定位兼容 Expo Go

## 改动原因

引入 `@react-native-community/geolocation` 后，机厅查找页顶层 import 会在 Expo Go 中因原生模块未链接而崩溃，路由也无法完成默认导出加载。开发仍需 Expo Go；正式 Android APK / EAS 构建继续走 LocationManager。

## 具体实现

1. 去掉对 community geolocation 的顶层 import。
2. 仅在 Android 且探测到 `RNCGeolocation` 已链接时再 `require`，并用 LocationManager 取坐标。
3. Expo Go、iOS 或未链接时回退 `expo-location`，避免启动崩溃。
4. 补充「未链接时回退 expo-location」单测。

## 期望输出

- Expo Go 可正常打开机厅查找（定位走 expo-location）。
- 自建 Android APK / EAS 仍优先 LocationManager（无 GMS）。
- iOS（含 EAS）继续只用 expo-location。
- 相关单测通过。

## 实际输出

- `vitest`：`acquire-arcade-gps-origin` 7 项通过；全量 unit 中另有无关的 `user-library` 历史标签顺序用例失败（本次未改该模块）。
- `typecheck` 通过；`lint` 无新增 error。
- Expo Go 不再因顶层 geolocation import 崩溃；自建 Android 包仍走 LocationManager。

# 随机歌曲筛选器与中二工具箱

## 改动原因

舞萌与 Phigros 的随机歌曲工具原有独立范围选项，与成绩页筛选语义不一致；中二节奏工具箱尚缺少随机歌曲和机厅查找。需要让三款游戏共享一致的随机页面结构，同时保留各自数据、筛选规则与持久化状态。

## 具体实现

- 新增无游戏分支的随机歌曲页面骨架和确定性无放回抽样函数，统一 1–4 数量、候选数、抽取、空态及结果区。
- 舞萌、Phigros 随机歌曲页改为复用各自完整成绩筛选栏；新增中二随机歌曲容器并复用中二成绩筛选栏。
- 三款游戏分别按现有规则处理曲库条件和成绩型条件；默认从全曲库抽取，仅在有效成绩型条件启用时要求对应成绩。
- 为舞萌、Phigros 升级游戏专属随机偏好 Schema 并迁移兼容旧数据，新增中二独立偏好；随机工具不读写成绩页筛选状态。
- 中二工具箱新增“随机歌曲”“机厅查找”，摘要同步更新，并支持两项工具置顶。
- 新增中二机型 title ID 3，首次进入机厅查找时默认选中中二节奏；已有按游戏保存的选择继续优先。
- 补充三游戏候选规则、固定种子抽样、偏好迁移、路由分派、工具箱、机厅默认值和页面 Host Tree/Style 合同测试。

## 期望输出

- 三款游戏的随机歌曲工具均可选择 1–4 条谱面，并以各自成绩页筛选器限定候选范围。
- 无成绩谱面默认可参与抽取；成绩型筛选启用后仅保留满足条件的已游玩谱面。
- 中二工具箱可进入随机歌曲和机厅查找，机厅首次默认筛选中二节奏。
- 旧随机偏好可安全迁移，三游戏偏好互相隔离，未知游戏不会误开舞萌随机页。
- 不修改版本号、Provider、曲库与成绩数据结构、用户曲库、备份格式或网络接口。

# 舞萌难度卡使用 DXRating 标签预设

## 改动原因

舞萌难度卡的本地标签原先复用了全局内置预设，和当前谱面的实际配置、难度与评价标签没有对应关系。DXRating 已能提供精确到谱面的标签，因此将这些标签直接作为难度卡预设更便于快速记录。

## 具体实现

- 为标签编辑器增加外部固定预设模式：固定预设可点按选择，但不能新增、删除、排序，也不能从历史标签复制到预设。
- 舞萌难度卡使用当前谱面匹配到的完整 DXRating 标签名称作为固定预设，包括卡片折叠区域未内联展示的第 5 个及以后标签。
- 难度卡不再读取或修改“爆发、交互、星星、鬼歌、大歌”等全局标签预设；歌曲级本地标签仍保留原有可编辑全局预设行为。
- 已保存的本地标签、历史标签选择、个人曲库存储与备份结构均保持不变。
- 更新 DXRating API 职责边界，并补充固定预设组件测试与歌曲详情接入测试。

## 期望输出

- 打开舞萌难度卡的标签预设时，只显示当前谱面的全部 DXRating 标签，不显示原有全局预设。
- DXRating 标签只能作为固定选项使用，不出现新增、删除、排序或复制为预设操作。
- 仍可选择历史标签和手动输入标签，歌曲级标签预设不受影响。

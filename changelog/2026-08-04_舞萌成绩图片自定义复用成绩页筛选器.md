# 舞萌成绩图片自定义器改为复用成绩页筛选器

日期：2026-08-04

## 改动原因

舞萌「生成成绩图片」的「自定义」模式原本维护一套独立的自定义筛选面板（数量、最小达成率、当前/过往版本 chips、成就下拉、寸、严格筛选），与成绩页 `MaimaiFilterBar`（难度、版本、类型、标签、定数、达成率区间、成就）存在大量重复逻辑，且缺少成绩页已有的难度/类型/标签/定数/达成率区间能力。本次将该面板改为复用成绩页筛选器组件，保持体验一致并减少重复实现。

## 具体实现

1. **`FilterAnchoredDropdown` 支持可选多选模式**
   - 新增 `multiple`、`selectedValues`、`onValuesChange`、`dropdownHeader`、`dropdownFooter` 可选参数。
   - 多选模式下列表项点击切换选中且不自动关闭，勾选图标使用 Ionicons checkbox；头部渲染快速操作区、底部渲染完成按钮；单选行为保持不变。
   - 下拉高度估算预留多选头部/底部空间，避免被截断。

2. **`MaimaiFilterBar` 新增可选多选版本模式**
   - 新增 `versionMulti`、`selectedVersions`、`currentVersionTitle`、`onVersionsChange` 可选参数，默认关闭，成绩页/曲库页行为不变。
   - 多选模式下版本行渲染复选框下拉：顶部提供「全部 / 当前版本 / 过往版本」快捷按钮，底部「完成」关闭；触发钮摘要显示「全部 / 单个版本名 / N 个版本 / 未选择版本」；中/日版本名切换沿用原有 locale 开关。
   - `buildMaimaiFilterSummary` 支持多选版本摘要。

3. **`best-image-custom.ts` 重构筛选模型**
   - `CustomBestImageFilters` 改为：`quantity`、`versions: string[]`（具体版本名多选）、`splitVersions`、`difficulty`、`type`、`constantMin/Max`、`achievementMin/Max`、`soloAchievement`、`multiAchievement`、`strictAchievement`、`nearMiss`、`selectedDxRatingTagIds`，另附 `dxRatingTagIndex` 与 `versionLabels`。
   - 过滤逻辑对齐成绩页：排除 UTAGE/unknown，按版本集合、难度、类型、定数区间、达成率区间、寸、成就（含严格）、DXRating 标签过滤。
   - `splitVersions` 语义从「当前/过往分节」改为「每个选中版本各一节」，节标题使用本地化版本名（跟随筛选器中/日切换）。
   - 删除 `parseBestImageMinimumAchievement` 与 `BestImageVersionFilter`（当前/过往）类型。

4. **`app/best-image.tsx` 自定义面板改为复用 `MaimaiFilterBar`**
   - 自定义面板内渲染 `MaimaiFilterBar`（`versionMulti` 开启、全部行启用），筛选状态为屏幕本地 state，与成绩页互不影响；版本选项由成绩记录版本名派生并默认全选。
   - 面板下方保留附加项：数量输入、区分版本（选中版本 <2 时禁用）、寸、严格筛选。
   - 移除原版本 chips、成就下拉、最小达成率输入及其状态/样式。

## 期望输出

- 自定义成绩图片面板与成绩页使用同一筛选器组件；版本为多选复选框，支持全部/当前/过往快捷选择与中/日版本名切换。
- 区分版本按每个选中版本分节，节标题为本地化版本名。
- 数量、寸、严格筛选保留；无选中版本或数量非法时导出禁用。
- 成绩页、曲库页、中二/Phigros 页面行为不受影响；单选用例全部保持。

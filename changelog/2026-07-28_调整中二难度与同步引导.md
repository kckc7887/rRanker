# 调整中二难度与同步引导

## 改动原因

中二节奏的曲库与成绩卡需要采用不同的难度文案，同时 WORLD'S END 的属性星级不能被普通 `level_value` 误当作定数。总览也需要展示真实曲库来源，并为玩家提供可操作的落雪离线同步流程。

## 具体实现

- 曲库普通谱面继续只显示定数，成绩与 Best 卡改为显示完整难度名和括号定数。
- 恢复 WORLD'S END 曲目、全成绩、Best 30 与 New 20，保留 `origin_id / kanji / star`，曲绘优先使用 `origin_id`。
- WORLD'S END 使用属性汉字与星级生成文案，并加入独立的静态冷暖霓虹渐变胶囊；展示逻辑不读取 `level_value`。
- 总览顶部同时展示成绩来源与中二曲库真实来源，下方数据状态仅保留来源和曲库。
- 启用“上传数据”入口并新增中二同步引导，提供代理服务器、端口、完整地址和微信离线同步链接的复制操作。
- 引导内同步复用总览刷新流程；仅在读取到非缓存的有效玩家数据后关闭引导。
- 补充 Provider、展示映射、曲库、成绩页、Best 页、总览和同步引导测试，并更新 API 协议说明。

## 期望输出

- 普通难度在不同页面使用正确文案，WORLD'S END 始终显示属性星级而非普通定数。
- WORLD'S END 可在曲库、成绩页和 Best 页正常显示，并使用正确曲绘与视觉主题。
- 玩家能在总览识别成绩和曲库来源，并按引导完成落雪中二数据同步。

## 实际输出

- WORLD'S END 数据已贯通曲库、全成绩与 B50，属性星级回退、曲绘 ID 和静态霓虹主题均已落地。
- 总览数据状态已精简并补齐真实曲库来源，同步引导的四项复制操作和刷新结果判定已完成。
- 类型检查通过；Lint 为 0 错误（仅保留仓库既有警告）；完整测试共 115 个测试文件、637 项测试全部通过。

# 2026-08-01 README 排版与路径修正

## 改动原因

按 review 意见修正 README 的小问题：图片路径使用反斜杠、代码块后缺空行、快速开始命令中 Windows 风格路径在 bash 中会被错误转义。

## 具体实现

- 将 README 中所有 `assets\images\` 图片路径统一为 `assets/images/`（跨平台更稳妥）。
- 将快速开始中的 `cd apps\mobile` 改为 `cd apps/mobile`，避免在 bash（git-bash）下被反斜杠转义为 `appsmobile`。
- 在 `## 🚀 快速开始` 代码块结束与 `## 🛠️ 技术栈` 之间补充空行，规范排版。

## 期望输出

README 渲染正常，路径兼容跨平台，排版统一。

## 实际输出

三处修改均成功应用，无其它改动。

# 统一信息栏展开与舞萌谱面版本筛选

## 改动原因

歌曲详情共享信息栏虽然已经复用同一个组件，但展开状态仍保存在各个单元格内部。点击一个被截断字段时只会展开该字段，信息栏整体高度已经改变，其他同样被截断的字段却仍保持两行，交互语义不一致。

舞萌曲库的 LXNS 适配器已经保存了谱面级 `versionId`，但版本筛选结果仍把整首歌的全部谱面交给歌曲行渲染，并继续使用单一歌曲版本文案。若同一首歌的 SD 与 DX 谱面分别在不同版本加入，筛选 SD 所属版本时仍会显示 DX 徽章，看起来像两类谱面都被归入歌曲或 SD 的版本。

## 具体实现

- 将 `SongMetadataTable` 的展开状态和各字段溢出状态提升到信息栏级别。
- 任意一个溢出字段触发展开后，信息栏内所有字段统一取消两行限制；再次点击任意溢出字段时全部恢复两行。
- 当信息项内容发生变化时，通过内容键重新建立信息栏状态，避免歌曲或版本名称切换后沿用旧的展开状态。
- 舞萌曲库未选择版本时，从每张谱面的 `versionId` 汇总版本文案；SD 与 DX 属于不同版本时明确显示为 `SD 版本 · DX 版本`。
- 选择具体版本后，只向歌曲行传递该版本真正包含的谱面，其他版本的 SD、DX 或 U·TA·GE 谱面徽章不再混入。
- 版本筛选结果中的版本文案与当前国服/日服名称选项同步，并与延迟筛选结果使用同一版本条件，避免筛选过渡期间展示错配。
- 增加同一首歌 SD、DX 分属两个版本的 LXNS 适配器测试，并覆盖未筛选、筛选 SD 版本和筛选 DX 版本三种曲库展示。
- 补充舞萌、Phigros、中二节奏信息栏整体展开和整体收起测试。

## 期望输出

- 点击信息栏任意一个被截断字段时，所有被截断字段同时完整展开；再次点击时统一恢复两行。
- 同一舞萌歌曲的 SD 与 DX 谱面可以分别归入各自的加入版本。
- 未筛选时能够看出 SD 与 DX 的不同版本；筛选某一版本时只显示属于该版本的谱面。
- 不改变 LXNS 原始数据、歌曲和谱面身份、成绩计算、用户数据、路由、个人曲库 Schema、备份格式或应用版本号。

## 实际输出

- 舞萌曲库测试确认未筛选时显示两套版本；筛选 DX 版本时只显示 DX 与对应定数，筛选 SD 版本时只显示 SD 与对应定数。
- 原有信息栏颜色、字号、行高、间距、分栏比例和 testID 未改；React Native Host 属性验证默认均为两行、展开后均为不限行、收起后均恢复两行。

- `npm run typecheck` 通过。
- 全部 Vitest 通过：96 个测试文件、586 项测试。
- 全部 Jest 通过：32 个测试套件、152 项测试；控制台仅保留既有 `act(...)` 警告。

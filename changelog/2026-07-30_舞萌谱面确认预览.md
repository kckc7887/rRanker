# 2026-07-30 舞萌查看谱面确认预览

## 改动原因

玩家需要在舞萌歌曲详情内直接查看并播放对应难度谱面，而不仅通过哔哩哔哩搜索确认。

## 具体实现

- Vendoring `@lxns-network/maimai-chart-engine`（MIT）到 `apps/mobile/src/features/maimai-chart-preview/engine/`，并编写精简 WebView 播放壳（解析、Canvas 渲染、预览曲、正解音、播放/暂停/拖动、流速/倍速）。
- `npm run build:chart-preview` 将播放器内联进 `assets/maimai-chart-preview/index.html`，附带 `sensor.webp` / `answer.wav`。
- Domain 映射：`maimaiChartPreviewChartId` / `EngineDifficulty` / Buddy 侧；路由页 `songs/chart-preview` 用 Expo Asset 落盘后 WebView 加载。
- 舞萌详情难度卡在「搜索谱面确认」下增加「查看谱面确认」；Buddy 宴谱弹出 1P/2P 选择。

## 期望输出

- 详情可见「查看谱面确认」，点击进入谱面确认页并加载对应难度。
- SD/DX/UTAGE/Buddy 的 chartId 与引擎难度映射正确。
- 单元测试与详情 Jest 入口测试通过。

## 实际输出

- Vitest：ID 映射与注入脚本测试通过。
- Jest：`m2-query` 覆盖普通入口与 Buddy 1P 选择。
- `tsc --noEmit` 通过；播放器产物已构建提交。

# 2026-08-05 中二节奏接入别名与歌曲信息卡

## 改动原因

中二节奏此前没有别名数据：曲库搜索只能命中曲名/ID/曲师/谱师，详情页也没有别名展示；详情页的「歌曲与版权信息」卡位于本地标签卡下方，且带有 LXNS/SEGA 版权声明。用户要求与舞萌板块保持一致：接入 LXNS 中二别名库（`/chunithm/alias/list`，与舞萌 `/maimai/alias/list` 端点不同，需单独甄别验证），详情页改为「歌曲信息」卡并移动到本地标签上方、去掉版权声明。所有实现一比一参考舞萌板块（`useDetailedCatalog` 合并、`LxnsCatalogProvider.getAliases`、`findMatchedAlias`/`matchNote`、详情页「歌曲信息」卡），不动任何公共逻辑。

## 具体实现

- `src/domain/chunithm.ts`：`ChunithmSong` 增加可选 `aliases` 字段；新增 `ChunithmAlias`、`ChunithmAliasSnapshot` 类型、`CHUNITHM_ALIAS_RESOURCE_KEY` 与纯函数 `chunithmAliasesForSong`（对齐舞萌 `aliasesForCatalogSong`，中二 id 无 U·TA·GE 映射，纯 map 查询）。
- `src/providers/chunithm-catalog-provider.ts`：新增 `AliasEntrySchema`/`AliasResponseSchema`（同舞萌，兼容裸数组与 `{aliases}` 包裹）、`mapChunithmAliases` 与 `getAliases()`，请求 `https://maimai.lxns.net/api/v0/chunithm/alias/list`（实测返回 736 条、数据干净），非法结构抛 `upstream_schema`，数据源标注「LXNS 中二别名库」。
- `src/services/chunithm-catalog-loader.ts`：新增 `CHUNITHM_ALIAS_SCHEMA_VERSION = 1` 与 `loadChunithmAliases()`（资源 key `chunithm-alias`，同舞萌 `aliases` 资源模式）。
- `src/hooks/use-chunithm-catalog.ts`：一比一复刻舞萌 `useDetailedCatalog`——queryFn 内 `Promise.allSettled` 并行加载别名并合并进各 `ChunithmSong.aliases`；别名失败降级为空别名并标注「别名暂不可用」，别名缓存过期标注「含缓存资源」。
- `src/hooks/use-game-data.ts`：chunithm-test 分支由 `queryClient.fetchQuery`（写共享键 `CHUNITHM_CATALOG_QUERY_KEY`）改为直接 `await loadChunithmCatalog()`，删除该分支独占的 `queryClient` 与 `CHUNITHM_CATALOG_QUERY_KEY` 导入。原因：舞萌的 game-data 走 ScoreService 自己的路径、从不写入曲库 hook 的查询键；中二此前共享同一查询键，概览页先挂载 `useGameData` 时会先写入未合并别名的曲库缓存，react-query 按键去重导致 hook 的合并 queryFn 不再执行——这是上次接入后「别名不显示、按别名搜索无结果」的根因。独立后共享键只有合并后的 hook 写入，与舞萌结构一致。
- `src/features/storage-management/game-storage-adapters.ts`：`CHUNITHM_ALIAS_RESOURCE_KEY` 加入 `CHUNITHM_CATALOG_RESOURCE_KEYS`（对齐舞萌 `'aliases'`），清除中二缓存时一并清除别名缓存。
- `app/(tabs)/search/index.tsx`（中二段）与 `src/components/chunithm/ChunithmSongRow.tsx`：搜索文档加入 `song.aliases`；新增本地 `chunithmMatchedAlias` 辅助函数（复用共享 `buildSearchDocument`/`searchDocumentMatches`，语义同舞萌 `findMatchedAlias`，不动共享工具）；仿舞萌对 filtered 计算 `matchedAliasBySongId` 并经 `ChunithmSongRow` 新增可选 `matchedAlias` prop → `GameSongRow.matchNote` 显示「别名：xxx」（同舞萌带冒号）+ `matchNoteStyle`；搜索框 placeholder 补「别名」为「曲名 / ID / 别名 / 曲师 / 谱师」。
- `src/components/chunithm/ChunithmSongDetail.tsx`：新增 `ChunithmAliasLine`（对齐舞萌 `AliasLine`：单行省略 + 超行「展开/收起」，testID `chunithm-alias-text`/`chunithm-alias-overflow-measure`）；详情区改为「歌曲信息」卡（标题 + 别名 + 版权 + 状态：禁用/锁定/可用），置于本地标签卡上方，删除「曲目数据与曲绘资源由 LXNS 公共服务提供。」「游戏、歌曲及相关素材版权归 SEGA…」两行声明及 `copyrightCard`/`footerNote` 样式。

## 期望输出

- 中二曲库搜索可用别名关键词命中，结果行在标题下方显示匹配别名小字「别名：xxx」；详情页「歌曲信息」卡显示别名、版权与状态，位于本地标签卡上方；LXNS/SEGA 版权声明不再出现；无别名歌曲显示「别名：无」。
- 无论从哪个页面先触发曲库加载（含 demo/测试账号的概览页），hook 读到的都是含别名数据，不依赖挂载顺序。
- 舞萌侧代码与既有行为零改动。

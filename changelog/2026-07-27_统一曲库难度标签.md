# 统一曲库难度标签

## 改动原因

中二节奏首版曲库的难度标签使用了浅色圆角矩形和难度缩写，与舞萌曲库的主题色胶囊视觉语言不一致；Phigros 曲库标签同时显示难度字样和定数，也显得信息重复。

## 具体实现

- 将中二节奏曲库的六种难度标签改为对应主题色实底、白色文字和胶囊形态。
- 中二节奏标签移除 `BAS`、`MAS`、`ULT`、`WE` 等文字及 WORLD'S END 属性，只显示格式化后的定数数字。
- 为 Phigros 共享难度标签增加可选的文字显示控制；仅在曲库卡片关闭难度字样，成绩卡等其他调用点保持原有展示。
- Phigros 曲库继续使用小圆角矩形和原有难度配色，仅强化纯数字定数的字重与不透明度。
- 新增中二和 Phigros 曲库标签测试，覆盖显示文字、主题色及圆角形态。

## 期望输出

- 中二节奏曲库难度标签与舞萌曲库保持同类视觉语言：主题色胶囊中只显示数字。
- Phigros 曲库难度标签维持自身的圆角矩形视觉语言，但只显示数字。
- Phigros 成绩卡、筛选器和其他页面的难度标签不受影响。

## 实际输出

- 中二节奏 BASIC 至 WORLD'S END 均已改为主题色纯数字胶囊。
- Phigros 曲库已移除 EZ、HD、IN、AT 字样，仅保留定数数字。
- `npm run typecheck` 通过。
- `npm run lint` 通过，0 个错误；保留仓库现有 20 条警告。
- 定向 UI 测试 2 个套件、3 项测试全部通过。

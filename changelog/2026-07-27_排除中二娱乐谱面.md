# 排除中二娱乐谱面

## 改动原因

WORLD'S END 与舞萌宴会场类似，主要属于娱乐性质谱面，不属于 rRanker 的查分范围。若继续保留在中二领域模型和曲库中，会使后续成绩列表、Best 与工具错误地把娱乐谱面作为正式查分内容。

## 具体实现

- LXNS 原始响应校验继续接受 `difficulty=5`，避免上游包含 WORLD'S END 时导致整份曲库校验失败。
- 在 Provider 映射进入应用领域模型前过滤 `difficulty=5`。
- 过滤后没有 BASIC 至 ULTIMA 常规谱面的歌曲不进入曲库；同时保留混合歌曲中的常规谱面。
- 将中二领域难度类型收窄为 `0-4`，移除 WORLD'S END 专属的 `origin_id`、`kanji` 与 `star` 字段。
- 曲绘统一按普通歌曲 ID 加载，不再保留 WORLD'S END 原曲映射逻辑。
- 将中二曲库缓存 schema 升级为 2，避免旧缓存继续展示娱乐谱面。
- 更新 API 协议文档和 Provider、曲库 UI 测试。

## 期望输出

- 中二曲库、关键词搜索及后续查分功能只处理 BASIC、ADVANCED、EXPERT、MASTER、ULTIMA。
- WORLD'S END 谱面和仅包含该类谱面的歌曲不会出现在应用领域数据中。
- LXNS 上游仍可正常返回完整公共曲库，不会因存在娱乐谱面而触发结构错误。

## 实际输出

- WORLD'S END 已在 Provider 领域映射阶段排除，领域类型与 UI 不再包含该难度。
- 缓存 schema 已升级，旧曲库缓存不会被继续复用。
- `npm run typecheck` 通过。
- `npm run lint` 通过，0 个错误；保留仓库现有 20 条警告。

- 完整测试通过：Vitest 85 个文件、458 项测试，Jest 23 个套件、116 项测试全部通过。

# 接入中二节奏成绩与 B50

## 改动原因

中二节奏已具备落雪账号与个人资料读取能力，但成绩页、最佳页仍为空态，总览也无法展示 Rating 的组成或主动刷新完整数据。需要补齐中二专属的成绩表达，并保持与舞萌相近的信息层级，同时遵循中二节奏自身的分数、评价和成就规则。

## 具体实现

- 接入落雪个人接口 `/api/v0/user/chunithm/player/bests`，与玩家资料、全部成绩并发读取；个人快照升级为 v2，保存 Best 30、Selection 10 与 New 20，并兼容 v1 缓存回退。
- 新增中二成绩展示映射：按曲目 ID 与难度关联公共曲库，补齐曲名、艺术家、谱师和定数；评价严格按整数 score 本地计算，所有页面继续排除 WORLD'S END。
- 新增中二专属成绩卡：大字显示带千位分隔的 score，右侧显示两位小数 Rating；第一行固定显示难度定数与评价，第二行依次显示单人成就、多人 FULL CHAIN 和通关成就。
- S 至 SSS 的分数与评价使用静态蓝白粉金渐变，SSS+ 使用同色流动版本；AJC、AJ、FC、FULL CHAIN、CLEAR 等成就按彩、铂金、金和灰色主题展示。
- 成绩页展示全部成绩，默认按单曲 Rating、score 降序，并支持曲名、ID、艺术家和谱师本地搜索，不增加高级筛选或详情跳转。
- 最佳页仅展示 Best 30 与 New 20，分区独立排序和编号，不展示 Selection 10。
- 总览 Rating 卡改为显示 Best30 与 New20 的实际平均 Rating；增加禁用的上传按钮和可用的落雪同步按钮，主动同步会刷新玩家、全部成绩及 B50。
- 更新中二 API 协议，并补充 Provider、评价边界、成就映射、页面排序搜索、B50 分区和总览操作测试。

## 期望输出

- 已同步的中二落雪账号可以在成绩页查看全部常规谱面成绩，在最佳页查看 Best 30 + New 20。
- 成绩卡的分数、评价、难度、成就和 Rating 符合中二节奏规则，WORLD'S END 不出现在查分数据中。
- 总览直接呈现两个 Rating 分区平均值，上传入口明确处于未开放状态，同步按钮可刷新三类个人数据。
- 不影响现有舞萌、Phigros、账号切换和通用页面行为。

# 谱面播放器烟花、全屏与打击音修复

## 改动原因

舞萌谱面确认播放器存在三类真机问题：烟花从非圆心位置触发时仍按固定半径绽放，无法覆盖圆形播放区的最远端；iOS 全屏固定为单一横屏方向，并因动态设置原生状态栏选项触发 `UIViewControllerBasedStatusBarAppearance` / RNScreens 报错，控制层隐藏后锁定按钮也随之消失；Android WebView 通过相对 `file://` 地址读取 `answer.wav` 不可靠，导致没有打击音。

## 具体实现

- 烟花峰值半径改为取“原圆心烟花大小”和“触发点到播放圆最远端距离”的较大值，并将成长、精灵缩放及消散遮罩统一使用该覆盖倍率。
- 原生全屏方向由固定 `landscape_left` 改为支持左右方向的 `landscape`；iOS 不再向 Stack 传递 Android 状态栏/导航栏隐藏选项，继续保留横屏、隐藏标题栏和 Home Indicator 自动隐藏。
- 全屏锁定按钮改为始终显示，并按 `safe-area-inset-right` 避开 iOS 安全区；底部控制层自动隐藏不再带走锁定入口。
- 将 35KB 打击音从缓存文件读取为 Base64，作为 `data:audio/wav` 注入播放器；WebView 内直接解码 Base64 后交给 Web Audio，保留原 URL/fetch 回退路径。
- 重新构建谱面播放器 HTML 与脚本产物，并补充烟花覆盖、音频解码、双向横屏、iOS 状态栏选项和锁定按钮 CSS 合同测试。

## 期望输出

- 烟花无论从播放圆内哪个触点触发，都能绽放到整个圆形播放界面的最远边缘。
- iOS 全屏不再出现状态栏/RNScreens 报错，可根据手机方向在左右横屏之间旋转，且锁定按钮始终可见。
- Android 播放谱面时能够正常播放打击音。

- `npm run lint` 通过，0 个错误；保留仓库现有 26 条警告。
- `npm run typecheck` 通过。
- 全部 Vitest 通过：107 个测试文件、676 个测试。
- 全部 Jest 通过：36 个测试套件、192 个测试。

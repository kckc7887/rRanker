# 谱面确认：流速扩域、倍速拨轮、设置持久化

## 改动原因
1. 流速 3-9 范围太窄，需扩至 0.1-20。
2. 倍速使用 slider 精度差，改为与流速一致的滚轮。
3. 流速数字显示多余，去掉。
4. 切换歌曲后设置（流速/倍速/音乐/正解音/音量）被重置，需跨歌曲持久化。

## 具体实现

### 流速
- `MainRenderer.setHiSpeed` 约束从 `>= 3 && <= 9` 改为 `>= 0.1 && <= 20`
- `main.ts` 常量 `HI_SPEED_MIN=0.1`、`HI_SPEED_MAX=20`
- 移除 `#hi-speed-value` 数字显示

### 倍速拨轮
- `index.html`：倍速 slider 替换为滚轮结构，范围 0.1-5、步进 0.1、默认 1.0
- `main.ts`：`createHiSpeedWheel` 重构为通用 `createWheel(min, max, step, default)`，移除 `valueLabel` 参数；流速和倍速共享同一轮子逻辑

### 设置持久化
- `ChartPreviewInjectConfig` 新增可选 `settings` 字段（含 hiSpeed/playbackSpeed/musicEnabled/soundEnabled/musicVolume/soundVolume），JSON 序列化时包含
- `main.ts`：初始化从 `config.settings` 读取恢复；任意设置变更时通过 `postStatus('settings', partial)` 上报
- `chart-preview.tsx`：导入 `expo-sqlite/kv-store`，`onMessage` 监听 `type === 'settings'` 写入 Storage；`useEffect` 准备 WebView 前从 Storage 读取设置并传入 config
- Storage key: `maimai-chart-preview-settings`

## 期望输出
- 流速支持 0.1-20，无数字显示
- 倍速为拨轮，范围 0.1-5
- 从 A 歌切到 B 歌，所有设置保持不变

## 实际输出
与期望一致。全部 102 测试文件 626 用例通过。

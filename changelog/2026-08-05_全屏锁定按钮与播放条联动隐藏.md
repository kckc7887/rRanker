# 2026-08-05 舞萌谱面确认全屏锁定按钮与播放条联动隐藏

## 改动原因

全屏模式下锁定按钮（`#fs-lock`）通过 `body.fullscreen #fs-lock { display: flex }` 常驻显示，既不随控制条 5 秒自动隐藏/触摸唤出，锁定时也没有单独的隐藏与唤出逻辑：锁定后只能点那个永远可见的锁按钮，点画布无任何反应。期望的是视频播放器式交互：未锁定时锁按钮与控制条一起隐藏/出现，锁定时全部隐藏、点画布只唤起解锁按钮。

## 具体实现

- `webview-player/main.ts`：用统一可见性状态 `fsControlsVisible` 取代原 `showFsOverlay`/`hideFsOverlay` 的分散逻辑。新增 `syncFsControlsVisibility()`（控制条可见 = `fsControlsVisible && !fsLocked`，锁按钮可见 = `fsControlsVisible`）、`showFsControls()`（置可见并设 5 秒自动隐藏）、`hideFsControls()`；进入全屏初始显示、退出全屏重置；画布点击去掉 `if (fsLocked) return`，改为可见则隐藏、隐藏则显示（锁定时自然只唤起解锁按钮）；锁定点击：锁定→全部隐藏，解锁→显示控制条；全屏时间线拖动仍唤出控制条。`fullscreenLock.ts` 纯函数不变。
- `webview-player/index.html`：`#fs-lock` 增加 `transition: opacity 0.2s`，新增 `#fs-lock.hidden { opacity: 0; pointer-events: none }` 与 `#fs-overlay.hidden` 保持一致。
- `tests/maimai-chart-preview-webview.test.ts`：新增回归断言，HTML 包含 `#fs-lock.hidden` 样式与过渡。

## 期望输出

- 全屏未锁定：锁按钮与控制条一起出现，5 秒后一起淡出；点画布一起切换显示/隐藏。
- 全屏锁定：控制条与锁按钮全部隐藏；点画布仅唤起解锁按钮，5 秒后自动再隐藏；点解锁后控制条与锁按钮一起出现，恢复未锁定逻辑。
- 退出全屏重置锁定状态，原有文案、testID、无障碍标签与普通模式行为不变。
